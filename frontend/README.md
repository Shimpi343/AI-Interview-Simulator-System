# Frontend - AI Interview Simulator

## Setup

1. Move into the frontend project:

```bash
ccd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000d frontend
```

2. Install dependencies:

```bash
npm install
```

3. Start dev server:

```bash
npm run dev
```

Frontend runs on `http://localhost:5173` and expects backend on `http://localhost:8000`.
